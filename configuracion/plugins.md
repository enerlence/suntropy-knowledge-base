# Plugins

Los plugins son funcionalidades extras que se activan desde **Configuracion > Plugins**. Permiten personalizar y optimizar los estudios segun las necesidades de cada empresa.

## Lista de plugins disponibles

| Plugin | Descripcion |
|--------|-------------|
| **Complementos de consumo** | Anade consumo extra a la [[curvas-de-consumo|curva de consumo]]: aire acondicionado, coche electrico, aerotermia |
| **[[equipos-personalizados|Equipos personalizados]]** | Crea categorias de equipos adicionales en el [[inventario]] (estructuras, cableado, mano de obra, protecciones...) |
| **Presupuesto avanzado** | Suma automaticamente todas las partidas de materiales (paneles + inversores + baterias + equipos personalizados) |
| **Recomendacion automatica de inversor** | Suntropy sugiere el inversor mas apropiado para la instalacion basandose en la potencia pico |
| **Trasladar consumo nocturno** | Desplaza un porcentaje del consumo a horas determinadas. Util para estudios comerciales |
| **Calculo del coste personalizado** | Trae el precio desde un CRM integrado (Odoo, etc.) mediante [[integraciones]] |
| **[[intervalos-potencia|Plantillas de intervalo de potencia]]** | Define ratios euros/Wp por rangos de potencia para calcular precios automaticamente |
| **Identificadores configurables** | Crea nombres automaticos para estudios con parametros (nombre cliente, potencia, fecha, etc.) |
| **Control de versiones** | Permite crear nuevas versiones (archiva la anterior) o variantes (ambas coexisten) de un estudio |
| **Imagenes externas** | Permite anadir imagenes externas (renders 3D, fotos de la instalacion) al estudio |
| **Plantillas de presupuesto** | Predefinir partidas y costes que se aplican automaticamente segun condiciones del estudio |
| **IVA reducido de materiales** | Para empresas que aplican IVA reducido cuando materiales son menos del 40% del coste total |
| **Chat en presupuestos compartidos** | Chat en tiempo real con el cliente a traves del enlace compartido del presupuesto |
