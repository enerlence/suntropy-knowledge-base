# Usuarios y Roles

Suntropy dispone de tres roles de usuario con diferentes niveles de permisos.

## Roles disponibles

| Rol | Permisos |
|-----|----------|
| **Administrador** | Acceso total. Puede hacer cualquier tipo de cambio: crear estudios, modificar configuraciones, gestionar [[inventario]], gestionar usuarios, cambiar precios, etc. |
| **Tecnico** | Puede crear y editar estudios, pero **no puede** cambiar configuraciones, precios ni equipos del inventario |
| **Comercial** | Solo puede generar PDFs de presupuesto. No puede crear ni editar estudios |

## Gestion de usuarios

### Crear un nuevo usuario
1. Ir a **Configuracion > Usuarios > Crear nuevo**
2. Rellenar los campos requeridos
3. Asignar el rol correspondiente

### Invitar por email
Se puede enviar una invitacion por email directamente con el rol asignado. El usuario recibira un enlace para registrarse.

### Personalizar permisos
Los permisos de cada rol se pueden consultar y personalizar en **Configuracion > Permisos**. Se muestra una tabla detallada de que puede hacer cada rol en cada funcion de la herramienta (el administrador no aparece porque tiene acceso a todo).
