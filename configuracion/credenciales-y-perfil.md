# Credenciales y Perfil de Usuario

## Cambiar credenciales de acceso

1. Ir a **Configuracion > Perfil de usuario**
2. Hacer clic en **"Editar"**
3. Modificar el **correo electronico** y/o hacer clic en **"Actualizar contrasena"**
4. Pulsar el boton **"Confirmar"** para guardar los cambios

## Otras configuraciones del perfil

Desde Configuracion tambien se puede cambiar:
- **Moneda**: Seleccionar la moneda para los calculos economicos
- **Idioma**: Cambiar el idioma de la interfaz

## Problemas de acceso

Si tienes problemas para acceder a tu cuenta, contacta con el equipo de soporte:
- Email: soporte@suntropy.es
- Chat de soporte dentro de la plataforma (en Configuracion)
